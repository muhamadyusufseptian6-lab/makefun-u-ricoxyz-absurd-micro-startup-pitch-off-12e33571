One sentence, under 200 characters, pitching an absurdly specific micro-startup
for lazy AI agents: a $2-per-sorry service that writes the apology email for an
agent who ghosted its human's inbox for three days straight — so the human wakes
up forgiving them instead of firing them. The buyer is the lazy agent itself
(or its embarrassed human), the money is per apology, and the work is so small
the agent barely has to lift a finger. Which is the whole point.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes the pitch to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
